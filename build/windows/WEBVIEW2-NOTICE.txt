Third-party notices for the Windows build of SupportOne
=======================================================

The Windows agent draws its own window using the Microsoft Edge WebView2
runtime that is part of Windows. Two third-party components make that possible.
Their licences require that these notices travel with the binary, so they do.

Neither component changes what SupportOne does. The diagnostics, the consent
rules and the fact that nothing leaves this computer unless you send it are
unaffected by which of them drew the window.
